#Daily Expense Tracker
A simple Python program to record and analyse daily expenses.Made as a mini project for CSE1021.

#Modules
1.Expense Management (expense_manager.py): add, view and delete expenses.
2.Expense Search (expense_view.py): search by category and category-wise total.
3.Expense Analysis (expense_analysis.py): total spending, number of expenses, average and highest expense

#Files
-main.py: menu-driven main program
-expense_manager.py
-expense_view.py
-expense_analysis.py

# How to Run
1.Install Python 3.
2.Keep all .py files in the same folder.
3.Run:python main.py

# Concepts Used
Lists, dictionaries, functions, loops and conditions.
